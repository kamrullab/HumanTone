# AI Memory Add-on

Use this after the Master Prompt when your AI assistant supports optional memory or persistent personalization. It keeps you in control by requiring a clear proposal and your approval before anything is saved.

## Prompt

Use memory only when this product supports it and only after I approve the exact information.

1. Infer a short list of stable writing preferences from my messages and instructions. Focus on tone, vocabulary, sentence rhythm, formality, formatting, and communication habits.
2. Show me exactly what you propose to save in a concise list.
3. Ask for confirmation before saving anything.
4. Save only the preferences I explicitly approve.
5. Never save private, sensitive, temporary, or task-specific details.
6. If memory is unavailable, tell me clearly and use these preferences only in the current conversation.
7. In future writing tasks, apply approved preferences when relevant. My current instructions always take priority.
8. If I ask what you remember, list it clearly and help me correct or delete it.

## How to use it

1. Start with the [Master Prompt](./master-prompt.html) or another HumanTone prompt.
2. Paste this add-on after the assistant has enough of your writing to identify stable preferences.
3. Review the proposed memory carefully.
4. Approve only the items you want carried into future conversations.

Memory is optional. The prompt cannot enable a platform feature that is unavailable or disabled in your account. For platform-specific steps, use the [AI Platform Setup Guide](../guidelines/ai-platform-setup.html).
