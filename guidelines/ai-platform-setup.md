# AI Platform Setup Guide

HumanTone prompts are plain-language instructions. You can paste them into most conversational AI assistants without special tools or integrations.

Features and availability can vary by account, plan, region, age, application, and administrator settings. Product interfaces also change over time. These instructions were reviewed on September 1, 2026.

## Choose your setup

For a one-time writing task, paste a HumanTone prompt directly into the conversation. For recurring work, use the platform's persistent instructions, project, style, Gem, Space, or memory feature when available.

## ChatGPT

1. For one conversation, paste the [Master Prompt](../prompts/master-prompt.html) before your writing request.
2. For recurring preferences, add a shorter HumanTone prompt to Custom Instructions or a Project.
3. If Memory is enabled, use the [Memory Add-on](../prompts/memory-addon.html) and approve only stable writing preferences you want saved.

ChatGPT treats Custom Instructions and Memory as different personalization controls. You can review and change them in settings. See the official [OpenAI personalization guide](https://learn.chatgpt.com/docs/personalize).

## Claude

1. Paste a prompt into a conversation for one-time use.
2. Use Profile Preferences for account-wide guidance, a Style for communication behavior, or Project Instructions for one project.
3. Treat past-chat personalization as optional because availability can vary by plan and account.

See Anthropic's official guide to [Claude personalization features](https://support.anthropic.com/en/articles/10185728-understanding-claude-s-personalization-features).

## Gemini

1. Paste a prompt into a regular Gemini conversation for one-time use.
2. Add HumanTone instructions to a Gem when you want a reusable writing assistant.
3. Past-chat memory is a separate feature and may not apply inside Gems or Gemini Live.

See Google's official guide to [Gemini personalization from past chats](https://support.google.com/gemini/answer/16598469).

## Microsoft Copilot

1. Paste the prompt into a Copilot conversation for a single task.
2. Add your stable voice profile to custom instructions when that option is available.
3. Use the Memory Add-on only when memory is enabled. Temporary Chat is useful when you do not want a conversation to use or update memory.

See Microsoft's official guide to [personalizing what Copilot remembers](https://support.microsoft.com/en-us/Microsoft-365-Copilot/personalize-what-microsoft-365-copilot-remembers).

## Perplexity

1. Paste the prompt into a thread for one-time use.
2. Add concise preferences to account custom instructions for recurring use.
3. Put a HumanTone prompt in a Space when you want project-specific writing behavior.

See Perplexity's official guides to [account instructions](https://www.perplexity.ai/help-center/en/articles/10352993-account-settings) and [Spaces](https://hub-prod.perplexity.ai/hub/faq/what-are-spaces).

## What HumanTone does not do

- It does not enable memory or bypass a platform's privacy controls.
- It does not guarantee that every product will follow every instruction exactly.
- It does not require memory. Every prompt can be used in a single conversation.
- It does not recommend saving private, sensitive, temporary, or task-specific information.

Your newest instruction should always take priority over saved preferences. Review stored personalization regularly and remove anything that no longer represents you.
